# Staff Navigator — Personnel Safety & GPS Command

**Live Website (GitHub Pages):** https://thanakornnopp-dev.github.io/staff-navigator/

## Features
- **Map-First Modern Dark SaaS UI** (Satellite / Dark / Street layer switcher)
